Privacy Policy

Core Privacy Principle: StatEngine is designed with an offline-first, zero-telemetry architecture. Your statistical research datasets, mathematical computations, figures, and generated reports remain strictly on your local device. We do not collect, transmit, store, or sell any personal information or dataset contents.

1. Information Collection and Processing

StatEngine functions locally on your Android device:

  • Data Files (CSV, TSV, XLSX, JSON): When you open a dataset file, the data is loaded directly into the application's local process memory for statistical calculations. It is never uploaded to any remote server or third-party cloud storage.
  • Analysis Results and Reports: All statistical outputs, descriptive metrics, generated charts, and PDF/HTML dossiers are created locally on your device.
  • No Tracking or Telemetry: We do not integrate third-party advertising SDKs, behavioural trackers, analytics tools, or device fingerprinting mechanisms.

2. Device Permissions and Storage Access

StatEngine requests only the minimum system permissions necessary to deliver core application functionality:

  • Read Access via System File Picker (SAF): When importing local datasets, StatEngine uses the secure Android Storage Access Framework (SAF). The application only accesses the specific file you explicitly choose.
  • Internet Permission (Optional URL Ingestion & Online Synthesis): StatEngine uses internet access exclusively when you explicitly ask the app to download an open dataset from a user-specified HTTP/HTTPS URL, or if you choose to query cloud AI generation using your own API key.
  • Write / Export Storage: Generated PDF and HTML reports are written only to standard app cache or designated user-selected export paths via Android FileProvider.

3. Artificial Intelligence Features

StatEngine provides built-in deterministic scientific synthesis that runs completely offline on your device with no remote calls. If you optionally choose to input a personal Google Gemini API key to query cloud synthesis:

  • Your API key is stored securely in your device's private app storage (SharedPreferences) and is never transmitted to GreenCube.
  • Any request sent to Google's API contains only the statistical summaries required for synthesis and is governed by Google's Privacy Policy.

4. Data Retention and Deletion

Because all data is processed in-memory or saved in your local device storage, closing the app or clearing the dataset immediately removes it from memory. You retain complete control over your datasets and exported reports at all times. Uninstalling the application removes all application-associated sandboxed data from your device.

5. Children's Privacy

StatEngine does not collect any personally identifiable information from any user, including children under the age of 13. The application is suitable for educational, academic, and professional scientific use.

6. Security

We value your trust in processing your sensitive research data. Because data computation is executed locally on-device without remote servers, your datasets are protected by your device's operating system security and sandboxing architecture.

7. Changes to This Privacy Policy

We may update our Privacy Policy periodically. Any updates will be published on this page with an updated effective date.
